# cidaas_webhook_events (Data Source)

The data source `cidaas_webhook_events` returns webhook-capable event IDs from your Cidaas instance
(`GET /webhook-srv/eventdescriptions?category=webhook`). Use these values in `cidaas_webhook.events`.

Ensure that the below scope is assigned to the client:
- cidaas:webhook_read

## Example Usage

```terraform
data "cidaas_webhook_events" "catalog" {}

output "webhook_event_ids" {
  value = [for e in data.cidaas_webhook_events.catalog.events : e.id]
}

resource "cidaas_webhook" "sample" {
  auth_type = "APIKEY"
  url       = "https://example.com/hook"
  events = [
    "ACCOUNT_MODIFIED"
  ]
  apikey_config = {
    key         = "api-key"
    placeholder = "test-apikey-placeholder"
    placement   = "query"
  }
}
```
