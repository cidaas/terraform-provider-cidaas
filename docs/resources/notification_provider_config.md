# cidaas_notification_provider_config (Resource)

Stores **provider credentials** for a service setup via **notification-srv** (`POST /{notifications_context_path}/providerconfigs`). Upsert by `_id` = `service_setup_id`.

**Recommended:** pass wizard-shaped JSON in `config_data_wo` with top-level `commProvider`, `commMethod`, and `schemaData` so the platform validates and maps fields server-side. The provider injects `configData.id` from `service_setup_id` when omitted.

**Verification** is manual (service-desk); use `cidaas_notification_service_setup.status` after refresh.

Destroy removes Terraform state only (no remote DELETE for provider configs).

**Scopes:** `cidaas:service_setups_read`, `cidaas:provider_config_write`.

-> **Note:** Write-Only argument `config_data_wo` is available to use in place of `config_data`. Write-only arguments are supported in HashiCorp Terraform 1.11.0 and later.

## Example Usage

```terraform
variable "twilio_account_sid" {
  type      = string
  sensitive = true
  ephemeral = true
}

variable "twilio_auth_token" {
  type      = string
  sensitive = true
  ephemeral = true
}

resource "cidaas_notification_service_setup" "twilio_sms" {
  name                  = "Twilio SMS"
  service_id            = "twilio-sms"
  communication_methods = ["sms"]
  description           = "Twilio SMS communication provider setup"
}

resource "cidaas_notification_provider_config" "twilio_sms" {
  service_setup_id = cidaas_notification_service_setup.twilio_sms.id

  # Write-Only: not stored in plan or state. Increment config_data_wo_version to rotate secrets.
  config_data_wo = jsonencode({
    commProvider = "custom-twilio-sms"
    commMethod   = "sms"
    schemaData = {
      accountSid = var.twilio_account_sid
      authToken  = var.twilio_auth_token
    }
  })
  config_data_wo_version = "1"
}
```

### Optional

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

### Read-Only

- `id` (String) Same as `service_setup_id`.
