# cidaas_federation_provider (Resource)

Manages federated identity providers on cidaas v4 (Trustdesk) via `/federation/providers`: catalog social providers (Apple, Google, …), custom OAuth2 / OpenID Connect, SAML and LDAP. Preferred replacement for the deprecated `cidaas_social_provider` and `cidaas_custom_provider`.

Set exactly one protocol block matching `standard_type`: `oauth2` for `OAUTH2` / `OPENID_CONNECT`, `saml` for `SAML`, `ldap` for `LDAP`.

## Example Usage

```terraform
variable "apple_client_id" {
  type = string
}

variable "apple_client_secret" {
  type      = string
  sensitive = true
}

variable "oidc_client_id" {
  type = string
}

variable "oidc_client_secret" {
  type      = string
  sensitive = true
  ephemeral = true
}

variable "oauth2_client_id" {
  type = string
}

variable "oauth2_client_secret" {
  type      = string
  sensitive = true
}

variable "ldap_bind_password" {
  type      = string
  sensitive = true
  ephemeral = true
}

# Catalog social provider (apple, google, microsoft, ...): cidaas owns the endpoints,
# so only the credentials are required.
resource "cidaas_federation_provider" "apple" {
  provider_name = "default_apple"
  provider_type = "apple"
  display_name  = "Apple"
  standard_type = "OAUTH2"

  oauth2 = {
    client_id     = var.apple_client_id
    client_secret = var.apple_client_secret
  }
}

# Custom OpenID Connect provider using discovery and a write-only secret (Terraform >= 1.11).
resource "cidaas_federation_provider" "custom_oidc" {
  provider_name = "my_oidc"
  provider_type = "custom"
  display_name  = "My OIDC"
  standard_type = "OPENID_CONNECT"
  domains       = ["example.com"]

  attribute_mapping = {
    email = {
      field_key    = "email"
      external_key = "email"
    }
    "customFields.department" = {
      field_key    = "customFields.department"
      external_key = "department"
      data_type    = "string"
    }
  }

  oauth2 = {
    client_id = var.oidc_client_id
    # Write-only: not stored in plan or state. Increment client_secret_wo_version to send a new secret.
    client_secret_wo         = var.oidc_client_secret
    client_secret_wo_version = "1"
    wellknown_endpoint       = "https://idp.example.com/.well-known/openid-configuration"
    userinfo_source          = "USERINFOENDPOINT"
    scopes                   = ["openid", "email", "profile"]
  }
}

# Custom OAuth2 provider with explicit endpoints.
resource "cidaas_federation_provider" "custom_oauth2" {
  provider_name = "my_oauth2"
  provider_type = "custom"
  display_name  = "My OAuth2"
  standard_type = "OAUTH2"

  oauth2 = {
    client_id              = var.oauth2_client_id
    client_secret          = var.oauth2_client_secret
    userinfo_source        = "USERINFOENDPOINT"
    authorization_endpoint = "https://auth.example.com/oauth/authorize"
    token_endpoint         = "https://auth.example.com/oauth/token"
    userinfo_endpoint      = "https://auth.example.com/oauth/userinfo"
  }
}

# SAML provider: display_name and meta_data are required. SP certificates are generated by cidaas
# and exposed as saml.sp_signing_certificates / saml.sp_encryption_certificates.
resource "cidaas_federation_provider" "saml" {
  provider_name = "corp_saml"
  provider_type = "custom"
  display_name  = "Corporate SAML"
  standard_type = "SAML"

  attribute_mapping = {
    email = {
      field_key    = "email"
      external_key = "http://schemas.xmlsoap.org/ws/2005/05/identity/claims/emailaddress"
      data_type    = "xsd:string"
    }
  }

  saml = {
    # IdP metadata XML, e.g. file("${path.module}/idp-metadata.xml").
    meta_data         = <<-EOT
      <EntityDescriptor xmlns="urn:oasis:names:tc:SAML:2.0:metadata" entityID="https://idp.example.com">
        <IDPSSODescriptor protocolSupportEnumeration="urn:oasis:names:tc:SAML:2.0:protocol">
          <SingleSignOnService Binding="urn:oasis:names:tc:SAML:2.0:bindings:HTTP-Redirect" Location="https://idp.example.com/sso"/>
        </IDPSSODescriptor>
      </EntityDescriptor>
    EOT
    sign_auth_request = true
    signature_config = {
      signing_algorithm = "RSA-SHA256"
      sign_targets      = ["authnrequest"]
    }
  }
}

# LDAP provider.
resource "cidaas_federation_provider" "ldap" {
  provider_name = "corp_ldap"
  provider_type = "custom"
  display_name  = "Corporate LDAP"
  standard_type = "LDAP"

  ldap = {
    connection_string = "ldaps://ldap.example.com:636"
    bind_dn           = "cn=admin,dc=example,dc=com"
    # Write-only: not stored in plan or state. Increment bind_credentials_wo_version to send a new password.
    bind_credentials_wo         = var.ldap_bind_password
    bind_credentials_wo_version = "1"
    base_dn                     = "dc=example,dc=com"
    default_groups = [
      { group_id = "CIDAAS_USERS", roles = ["USER"] }
    ]
  }
}
```

## Schema

### Required

- `provider_name` (String) Unique technical name of the provider per tenant. Only letters, digits, `_` and `-` are allowed. Changing it forces a new resource.
- `provider_type` (String) Platform of the provider (API field `provider`; `provider` itself is a reserved Terraform meta-argument): a catalog social key (`amazon`, `apple`, `discord`, `facebook`, `foursquare`, `github`, `gitlab`, `google`, `instagram`, `linkedin`, `microsoft`, `netid`, `netid_qa`, `officeenterprise`, `paypal`, `paypal_sandbox`, `salesforce`, `slack`, `tiktok`, `twitter`, `wordpress`, `x`, `yahoo`, `yammer`) or `custom`. Catalog social providers do not need endpoint URLs or `userinfo_source`.
- `standard_type` (String) Protocol of the provider. One of `OAUTH2`, `OPENID_CONNECT`, `SAML`, `LDAP`.

### Optional

- `attribute_mapping` (Attributes Map) Attribute mapping from the external provider to cidaas fields. The map key must equal `field_key`: a system field (e.g. `email`, `given_name`), `customFields.<key>` or `identityCustomFields.<key>`. (see [below for nested schema](#nestedatt--attribute_mapping))
- `description` (String) Description of the provider.
- `display_name` (String) Display name shown in the UI. Required when `standard_type` is `SAML`.
- `domains` (List of String) Allowed domains for this provider.
- `enabled_for_admin_portal` (Boolean) Whether the provider is available for the admin portal login.
- `ldap` (Attributes) LDAP configuration. Required when `standard_type` is `LDAP`. (see [below for nested schema](#nestedatt--ldap))
- `logo_url` (String) URL of the provider logo.
- `oauth2` (Attributes) OAuth2 / OpenID Connect configuration. Required when `standard_type` is `OAUTH2` or `OPENID_CONNECT`. (see [below for nested schema](#nestedatt--oauth2))
- `owner` (String) Owner of the provider. One of `admin`, `client`, `core`, `system`. Defaults to `client` (visible in the Admin UI).

## Import

Import is supported using the following syntax:

```shell
# In the import statement, the identifier is the unique id of the federation provider.
# For example:

terraform import cidaas_federation_provider.sample 3f453233-92d4-475b-b10e-813fbd476c50
```

After import, run `terraform plan`: secrets are imported into `oauth2.client_secret` / `ldap.bind_credentials`, and `oauth2.wellknown_endpoint` is not returned by the API. Adjust the configuration (for example to the write-only attributes) until the plan is clean.
